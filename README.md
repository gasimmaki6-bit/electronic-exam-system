# نظام الامتحانات الإلكتروني

نظام امتحانات إلكتروني كامل مبني بلغة Python باستخدام إطار Flask، يدعم ثلاثة أدوار:
**مدير (Admin)**، **أستاذ (Teacher)**، **طالب (Student)**، مع تسجيل دخول بكلمات مرور مشفّرة
(hashed) ونظام لمنع الغش أثناء أداء الامتحان.

## المميزات

- تسجيل دخول آمن (كلمات المرور مشفّرة عبر `werkzeug.security`، لا يتم تخزين أي كلمة مرور كنص صريح).
- **المدير**:
  - إنشاء/إيقاف/حذف حسابات الأساتذة والطلاب، عرض إحصائيات عامة.
  - **توليد حسابات تلقائياً بالجملة** (اسم مستخدم وكلمة مرور عشوائيين لعدد كبير من الطلاب/الأساتذة دفعة واحدة)،
    مع إمكانية طباعة/حفظ القائمة الناتجة فوراً.
  - توليد سريع لاسم مستخدم وكلمة مرور عشوائيين عند إنشاء حساب فردي (زر "توليد تلقائي").
- **الأستاذ**:
  - إنشاء امتحانات، تحديد وقت البداية/النهاية والمدة، تفعيل/إيقاف الامتحان.
  - إضافة **4 أنواع من الأسئلة**: اختيار من متعدد، صح أو خطأ، مقالي (إجابة نصية حرة)، توصيل (مطابقة مصطلحات بأرقام).
  - **إرفاق صورة بأي سؤال** (رسم، خريطة، صورة تشريحية...).
  - **تصحيح الأسئلة المقالية يدوياً** بعد تسليم الطلاب.
  - **لوحة تحليلات كاملة لكل امتحان**: متوسط/وسيط/أعلى/أدنى نسبة، نسبة النجاح والرسوب، متوسط الوقت
    المستغرق، متوسط المخالفات، عدد حالات التسليم التلقائي، رسوم بيانية لتوزيع الدرجات ولصعوبة كل سؤال
    على حدة (نسبة الإجابة الصحيحة لكل سؤال)، وجدول تفصيلي لكل طالب.
- **الطالب**:
  - عرض الامتحانات **المتاحة الآن** والامتحانات **القادمة** (بجدول مواعيد منفصل) بشكل واضح.
  - أداء الامتحان بأنواع الأسئلة الثلاثة (اختيار من متعدد، مقالي، توصيل).
  - صفحة **"درجاتي"** تعرض كل نتائجه في الامتحانات السابقة مع النسبة العامة ومتوسطه الكلي.
- **دعم لغتين (عربي/إنجليزي)**: زر 🌐 في الشريط العلوي يبدّل كامل واجهة النظام بين العربية (RTL)
  والإنجليزية (LTR) فوراً، مع حفظ اختيار المستخدم لجلسته.
- **خط Cairo** (من Google Fonts) لواجهة أوضح وأجمل، مع رجوع تلقائي لخط النظام الافتراضي عند عدم توفر
  إنترنت.
- **نظام منع الغش**:
  - عدّاد زمني تنازلي مع تسليم تلقائي عند انتهاء الوقت.
  - كشف الخروج من التبويب / تصغير النافذة (`visibilitychange` و `blur`).
  - إجبار وضع ملء الشاشة، وكشف الخروج منه.
  - تعطيل النقر بزر الفأرة الأيمن، والنسخ، واللصق، والقص.
  - تعطيل اختصارات أدوات المطور (F12, Ctrl+Shift+I...).
  - تحذير عند محاولة إغلاق الصفحة أو مغادرتها.
  - بعد تجاوز عدد معيّن من المخالفات (افتراضياً 3) يتم تسليم الامتحان تلقائياً.
  - خلط ترتيب الأسئلة والاختيارات لكل طالب (اختياري لكل امتحان) لتقليل الغش بالمقارنة بين الطلاب.

> ملاحظة مهمة: منع الغش من طرف المتصفح (JavaScript) لا يمكن أن يكون مضموناً بنسبة 100%
> لأن أي مستخدم متقدم تقنياً يمكنه تجاوز قيود المتصفح. لحماية أقوى في بيئة إنتاجية حقيقية
> يُفضّل إضافة مراقبة بالكاميرا (Proctoring) وربط الامتحان بجهاز/شبكة محددة، وهذا خارج نطاق
> هذا المشروع التعليمي.

## أنواع الأسئلة المدعومة

| النوع | الوصف | طريقة التصحيح |
|---|---|---|
| **اختيار من متعدد** | حتى 4 اختيارات، إجابة واحدة صحيحة | آلي فوري |
| **صح أو خطأ** | سؤال بإجابة ثنائية (صح/خطأ) | آلي فوري |
| **إجابة قصيرة** | الطالب يكتب كلمة/عبارة قصيرة تُقارَن نصياً بإجابة نموذجية | آلي فوري (بدون حساسية لحالة الأحرف أو المسافات الزائدة) |
| **ترتيب** | عناصر تظهر للطالب بترتيب عشوائي وعليه اختيار الموضع الصحيح لكل عنصر | آلي فوري (درجة جزئية حسب عدد المواضع الصحيحة) |
| **مقالي** | الطالب يكتب إجابة نصية حرة | يدوي من الأستاذ بعد التسليم |
| **توصيل** | قائمة مصطلحات يقابلها قائمة تعريفات مرقّمة بترتيب عشوائي | آلي فوري (درجة جزئية بحسب عدد التوصيلات الصحيحة) |

أي سؤال من الأنواع الستة يمكن أن يحتوي على **صورة مرفقة** اختيارية.

## ميزات إدارية إضافية

- **المواد الدراسية**: يُنشئها المدير من "📚 المواد الدراسية"، ويمكن تعيين أستاذ مسؤول لكل مادة،
  ثم يختار الأستاذ المادة عند إنشاء امتحان جديد (اختياري).
- **سجل التدقيق (Audit Log)**: يسجّل تلقائياً كل عمليات الدخول/الخروج، إنشاء/حذف/إيقاف المستخدمين،
  إنشاء/نشر/إيقاف الامتحانات، وتصحيح الأسئلة المقالية. يظهر في "📋 سجل التدقيق" من لوحة المدير.
- **الإشعارات**: كل طالب يتلقى إشعاراً تلقائياً عند نشر امتحان جديد، وعند اكتمال تصحيح أسئلته
  المقالية. أيقونة 🔔 في الأعلى تعرض عدد الإشعارات غير المقروءة.
- **آخر تسجيل دخول**: يُسجَّل تلقائياً لكل مستخدم (`last_login_at`) في قاعدة البيانات.

> إذا احتوى الامتحان على سؤال مقالي واحد على الأقل، ستظهر نتيجة الطالب كـ **"جزئية"** فور التسليم،
> إلى أن يقوم الأستاذ بتصحيح الأسئلة المقالية من صفحة "نتائج الامتحان" ← زر "تصحيح المقالي"،
> وعندها تُحدَّث النتيجة النهائية تلقائياً.

## متطلبات التشغيل

- Python 3.9 أو أحدث.
- اتصال بالإنترنت لمرة واحدة فقط لتثبيت المكتبات (pip install).

## خطوات التشغيل المحلي

### 1. فك ضغط المشروع وفتح الطرفية (Terminal / CMD) داخل مجلد `exam_system`

### 2. إنشاء بيئة افتراضية (اختياري لكن مستحسن)

على Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

على macOS / Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

### 4. تهيئة قاعدة البيانات وإنشاء حساب المدير الافتراضي

```bash
python init_db.py
```

سيظهر لك في الطرفية اسم المستخدم وكلمة المرور الافتراضيين لحساب المدير:
```
اسم المستخدم: admin
كلمة المرور: Admin@123
```
**يجب تغيير هذه الكلمة أو إنشاء مدير جديد وحذف/إيقاف هذا الحساب في بيئة حقيقية.**

### 5. تشغيل الخادم

```bash
python app.py
```

سيبدأ الخادم على العنوان:
```
http://127.0.0.1:5000
```

افتح هذا الرابط في المتصفح.

### 6. تسجيل الدخول كمدير أولاً

- سجّل الدخول بحساب `admin`.
- من لوحة تحكم المدير اضغط "إضافة مستخدم" لإنشاء:
  - حساب أستاذ واحد أو أكثر (الدور: أستاذ).
  - حسابات الطلاب (الدور: طالب).

### 7. تسجيل الدخول كأستاذ

- أنشئ امتحاناً جديداً (العنوان، المدة، وقت البدء/الانتهاء، خيارات الخلط).
- أضف الأسئلة (اختيار من متعدد، مع تحديد الإجابة الصحيحة والدرجة).
- فعّل الامتحان (يكون مفعّلاً تلقائياً عند الإنشاء).

### 8. تسجيل الدخول كطالب

- من لوحة تحكم الطالب، اضغط "بدء الامتحان".
- اضغط زر "ابدأ الامتحان بوضع ملء الشاشة" لتفعيل نظام منع الغش بشكل كامل.
- أجب عن الأسئلة ثم اضغط "تسليم الامتحان"، أو انتظر التسليم التلقائي عند انتهاء الوقت
  أو تجاوز عدد المخالفات.

## تخصيص عدد المخالفات المسموح بها قبل التسليم التلقائي

عدّل القيمة التالية في ملف `config.py`:
```python
MAX_TAB_SWITCH_VIOLATIONS = 3
```

## إصلاحات مهمة (مسودة/نشر الامتحان والتوقيت)

- **الامتحان الآن يُنشأ كمسودة (📝) ولا يظهر للطلاب إطلاقاً** حتى يضغط الأستاذ صراحة زر
  **"🚀 نشر الامتحان"** (متاح في صفحة إدارة الأسئلة وفي لوحة تحكم الأستاذ). لا يمكن نشر
  امتحان بدون أسئلة.
- **تم توحيد كل حسابات الوقت في النظام لتستخدم التوقيت المحلي للجهاز** بدل الخلط بين
  التوقيت المحلي (لحقلي بداية/نهاية الامتحان) وتوقيت غرينتش UTC (لحساب "الآن") — هذا
  الخلط كان يسبب عدم ظهور الامتحان للطلاب لساعات حسب فرق التوقيت المحلي عن UTC.
- **أُضيف رابط عودة كان ناقصاً** في صفحتي الإشعارات وبنك الأسئلة (كانتا بلا مخرج).

## ميزات إضافية

- **الوضع الليلي 🌙**: زر في الشريط العلوي يبدّل بين الوضعين الفاتح والداكن لكامل
  الموقع، ويُحفَظ الاختيار في المتصفح (لا يحتاج تسجيل دخول من جديد).
- **تصدير نتائج الامتحان CSV**: زر في صفحة نتائج كل امتحان يُصدّر جدول النتائج كاملاً
  (الاسم، الدرجة، النسبة، المخالفات...) كملف يمكن فتحه في Excel مباشرة.
- **تكرار الامتحان 🗂️**: زر في لوحة تحكم الأستاذ ينسخ امتحاناً كاملاً (بكل أسئلته
  الستة الأنواع) كمسودة جديدة منفصلة تماماً — دون التأثير على الأصل أو نتائجه، ومفيد
  لإعادة استخدام امتحان فصل دراسي سابق.
- **تنبيه بصري عند اقتراب انتهاء الوقت**: العداد التنازلي ينبض بلون أحمر داكن تلقائياً
  عند تبقي أقل من دقيقتين على انتهاء الامتحان.
- **بحث فوري في قوائم المستخدمين**: مربع بحث في لوحة المدير يُصفّي جداول الأساتذة/الطلاب
  فور الكتابة بدون إعادة تحميل الصفحة.


## ملاحظات أمنية للاستخدام في بيئة حقيقية (Production)

1. غيّر قيمة `SECRET_KEY` في `config.py` إلى قيمة عشوائية سرية قوية.
2. استخدم قاعدة بيانات حقيقية (PostgreSQL/MySQL) بدلاً من SQLite عند وجود عدد كبير من المستخدمين
   المتزامنين، عن طريق تغيير `SQLALCHEMY_DATABASE_URI` في `config.py`.
3. لا تشغّل السيرفر بوضع `debug=True` في الإنتاج؛ استخدم خادم WSGI حقيقي مثل `gunicorn` خلف Nginx.
4. فعّل HTTPS دائماً في بيئة الإنتاج.
5. فعّل حماية CSRF (يمكن إضافة مكتبة `Flask-WTF`) للنماذج في بيئة إنتاجية حقيقية.

## استكشاف الأخطاء الشائعة

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError` | تأكد من تفعيل البيئة الافتراضية وتنفيذ `pip install -r requirements.txt` |
| صفحة فارغة أو خطأ 500 | تأكد من تنفيذ `python init_db.py` قبل `python app.py` |
| نسيان كلمة مرور المدير | احذف ملف `exam_system.db` وأعد تشغيل `python init_db.py` (سيُعاد إنشاء قاعدة البيانات من جديد وتُفقد كل البيانات) |
| المنفذ 5000 مستخدم | عدّل السطر الأخير في `app.py`: `app.run(debug=True, host="0.0.0.0", port=5001)` |
| الرسوم البيانية في صفحة التحليلات لا تظهر | صفحة التحليلات تحمّل مكتبة الرسوم (Chart.js) من الإنترنت؛ إن كان الجهاز بلا اتصال ستبقى كل الأرقام والجداول ظاهرة، فقط الرسم البياني لن يُرسم |
| الخط يظهر بالخط الافتراضي للنظام وليس Cairo | خط Cairo يُحمَّل من Google Fonts؛ بدون اتصال إنترنت يعمل النظام بخط النظام الافتراضي تلقائياً بدون أي كسر في التصميم |
| رسالة خطأ متعلقة بأعمدة ناقصة في قاعدة البيانات بعد تحديث النظام | احذف ملف `exam_system.db` وشغّل `python init_db.py` من جديد (راجع تنبيه الترقية أعلاه) |
| فشل رفع صورة السؤال | تأكد أن الصيغة من ضمن (png, jpg, jpeg, gif, webp) وأن حجمها أقل من 5 ميجابايت |
